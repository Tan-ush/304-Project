Model selection
You mention using adjusted R-squared to compare different models. Adjusted R-squared is not built as a formal model selection criterion, unlike AIC, BIC, or LASSO. Please use one of these instead.

Research question 2
Research question 2 compares students who skip both lecture and tutorial against students who do not skip both. I understand the reasoning behind this grouping. A student might attend lectures but skip tutorials because they find lectures more valuable, or the reverse if the TA is stronger than the lecturer. That said, grouping by "skips both" versus "does not skip both" may combine different skipping patterns into one group in a way that obscures what is actually driving the effect. Please reconsider how you define these groups, or consider a design that accounts for lecture and tutorial attendance separately rather than combining them into a single comparison.

Research questions 1 and 3
RQ1 uses simple linear regression, and RQ3 uses multiple linear regression with a set of covariates that already includes the variable from RQ1. If an effect looks weaker in the multiple regression model, that would already tell you the variable is not that strong once other predictors are accounted for. RQ1 and RQ3 are testing very similar things, so there is no need for simple linear regression alongside multiple linear regression. Please reconsider RQ1.
